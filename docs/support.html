macfeel · support

支援

macfeel 1.0 · macOS 14 或以上

常見問題

套用之後見不到效果？
部分設定要重開 app、重啟 Dock／Finder，或者登出再登入才生效。每一列右邊的 ⓘ 會寫明。 在 Mac App Store 版本中，基於沙盒限制，macfeel 不能代你重啟 Dock，請自行登出再登入。
如何還原？
按底部「還原」會回到最近一次快照（每次套用前自動建立）。單獨一項可以在 ⓘ 內按「還原此項」， 它會刪除該鍵，回到 macOS 預設。命令行版本另有 macfeel restore。
會不會改壞系統？
macfeel 只寫入使用者層級的偏好設定，不使用輔助使用權限、不修改 SIP、不安裝核心擴充。 所有改動都可以還原；最壞情況是登出再登入。
支援哪些 macOS 版本？
macOS 14（Sonoma）或以上。部分鍵值在較新的 macOS 已被 Apple 移除，該列會顯示為「未設定」。
